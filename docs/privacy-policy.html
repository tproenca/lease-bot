Política de Privacidade

Última atualização: 19 de maio de 2026

O Lease Assistant é uma ferramenta conversacional que ajuda proprietários brasileiros a gerar contratos de locação, coordenar assinaturas eletrônicas e acompanhar pagamentos de aluguel por meio de um Custom GPT da OpenAI.

1. Dados coletados

Coletamos apenas os dados necessários para o funcionamento do serviço:

  • Conta Google — nome e endereço de e-mail, obtidos via Google OAuth no momento do cadastro.
  • Token de acesso ao Google Drive — armazenado de forma segura para que o sistema possa criar, editar e arquivar documentos na sua conta do Google Drive.
  • Número de WhatsApp — utilizado para enviar notificações de assinatura e lembretes de pagamento.
  • Chave de API do Autentique — armazenada de forma segura para envio de contratos para assinatura eletrônica.
  • Dados de imóveis e inquilinos — nome, CPF, WhatsApp e identificadores de pasta no Google Drive; necessários para geração de contratos.
  • Registros de pagamento — mês de referência, valor e data de pagamento; utilizados para identificar inadimplência e disparar lembretes.

Não coletamos dados de inquilinos além do necessário para geração de documentos e notificações.

2. Como os dados são armazenados

  • Banco de dados — Supabase PostgreSQL hospedado na região sa-east-1 (São Paulo). Todos os dados estão protegidos por criptografia em repouso (AES-256) e por políticas de segurança em nível de linha (Row Level Security), que garantem que cada proprietário acesse apenas seus próprios dados.
  • Documentos — contratos gerados, PDFs exportados e documentos assinados são armazenados exclusivamente no Google Drive do próprio proprietário. O Lease Assistant não mantém cópias em armazenamento próprio.
  • Tokens e chaves — o token de atualização do Google e a chave de API do Autentique são armazenados no banco de dados com criptografia em nível de infraestrutura e nunca são registrados em logs ou incluídos em respostas de erro.

3. Compartilhamento de dados

Os seus dados são compartilhados apenas com os seguintes serviços terceiros, estritamente necessários para o funcionamento do sistema:

  • Google Drive API — para criação, edição e arquivamento de documentos na sua conta.
  • Autentique — para envio de contratos para assinatura eletrônica e notificação dos signatários via WhatsApp.
  • Meta WhatsApp Business Cloud API — para envio de lembretes de pagamento aos inquilinos.
  • OpenAI — a interface do sistema é um Custom GPT; as conversas estão sujeitas à política de privacidade da OpenAI.

Não vendemos, alugamos nem compartilhamos seus dados com terceiros para fins de marketing ou publicidade.

4. Retenção de dados

Os dados são mantidos enquanto a sua conta estiver ativa. Você pode solicitar a exclusão de todos os seus dados a qualquer momento entrando em contato pelo e-mail abaixo. A exclusão é irreversível e remove todos os registros de imóveis, inquilinos e pagamentos. Os documentos armazenados no seu Google Drive não são afetados.

5. Seus direitos (LGPD)

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você tem direito a:

  • Confirmar a existência de tratamento de dados pessoais;
  • Acessar os dados que mantemos sobre você;
  • Corrigir dados incompletos, inexatos ou desatualizados;
  • Solicitar a eliminação dos dados pessoais tratados;
  • Revogar o consentimento a qualquer momento.

Para exercer qualquer um desses direitos, entre em contato pelo e-mail abaixo.
